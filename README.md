# xwing

Web app for playing Heroes of the Aturi Cluster (HotAC) and its community descendants as a co-operative X-Wing campaign companion.

Editions planned: 1st Edition, 2nd Edition, 2.5 Edition, and an X-Wing Alliance (XWA) edition.

Status: v0.1 playable as a single file. Open `index.html` in a browser. See [design.md](design.md) for the full plan and [docs/sources.md](docs/sources.md) for the source inventory.
