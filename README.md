# xwing

Web app for X-Wing squad building, a card and ship database, and a campaign and rules library for 1st Edition, 2.0, 2.5, AMG 2.5 and XWA.

Target URL: https://ianmcgo.github.io/xwing

Status: prototype v0.2 in index.html; the build plan is in [design.md](design.md). Sources are listed in [docs/sources.md](docs/sources.md).
