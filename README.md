# xwing

Web app for X-Wing squad building, a card and ship database, and a rules and campaign library for 1st Edition and XWA.

Target URL: https://ianmcgo.github.io/xwing

Status: prototype v0.6 with a 1st Edition squad builder in index.html; the build plan is in [design.md](design.md). Sources are listed in [docs/sources.md](docs/sources.md).
